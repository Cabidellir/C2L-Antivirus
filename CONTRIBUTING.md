# Contributing to C2L Antivirus

O C2L Antivirus é desenvolvido de forma incremental e orientada por documentação.

## Antes de contribuir

Consulte:

- README.md
- docs/README.md
- documentação específica do componente em desenvolvimento

## Princípios

- Segurança por design.
- Mudanças pequenas e revisáveis.
- Testes para funcionalidades relevantes.
- Documentação de decisões arquiteturais.
- Não executar amostras potencialmente maliciosas fora de ambientes isolados.

## Desenvolvimento

Novas funcionalidades devem, sempre que possível, ser acompanhadas por:

1. testes;
2. documentação;
3. atualização do changelog;
4. explicação da decisão técnica quando houver impacto arquitetural.
