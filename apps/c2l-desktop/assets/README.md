# C2L identity

Original geometric shield artwork: purple body, cyan C and gold ascending stroke.
`c2l-shield.svg` is the editable vector master. PNG and raw RGBA are 256 × 256;
ICO includes 16, 24, 32, 48, 64, 128 and 256 px variants. The transparent mark
is shared by the sidebar, window and executable resource. No external fonts or artwork.

The interface uses a static, clipped 24 px micro-grid at low opacity, raised
summary cards and a gold outline for the selected navigation item. Both themes
retain their existing readable text colors. Texture is cached, not reloaded per frame.
