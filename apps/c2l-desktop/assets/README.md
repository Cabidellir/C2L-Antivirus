# C2L identity

The user selected option 1, brushed metal, on 2026-10-20.
`c2l-shield-brushed-master.png` is the selected generated artwork with transparency.
PNG and raw RGBA runtime assets are 256 × 256; ICO includes 16, 24, 32, 48,
64, 128 and 256 px variants. All are derived from that same master using Lanczos
resampling. The sidebar, window and Windows executable share this artwork.

`c2l-shield.svg` preserves the original flat geometric design for reference;
it is not the master for the metallic finish. The metallic variant was created
with the built-in image generation tool from that original mark: brushed purple
anodized metal shield, raised cyan C, polished gold angular stroke, soft bevels
and studio highlights, front view on transparent background.

The interface uses a static, clipped 24 px micro-grid at low opacity, raised
summary cards and a gold outline for the selected navigation item. Both themes
retain their existing readable text colors. Texture is cached between frames.
